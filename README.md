# ❄️ 삿포로, 겨울 동화 — 세 가족 여행 2027

2027.1.8(금) – 1.12(화) · 어른 6 + 아이 4 (중2 딸 3 · 초4 아들 1), 총 10명의 삿포로 겨울 여행 가이드 웹페이지입니다.

👉 **보기: https://hs-code97.github.io/japan/**

## 구성
- `index.html` / `style.css` / `app.js` — 모바일용 페이지
- `data.js` — **일정 1**의 일정·장소·메뉴 데이터
- `data-plan-2.js` — **일정 2**의 독립 데이터
- `data-plan-3.js` — **일정 3**의 독립 데이터
- `plan-options.js` / `plan-loader.js` — 안 선택·공유 주소·데이터 로딩

## 일정안 비교와 수정 규칙
- 가족에게는 기존 주소 하나를 공유합니다. 모든 화면에서 일정 1·2·3 버튼이 함께 보입니다.
- `?plan=2` 또는 `?plan=3`으로 바로 열어도 나머지 안의 버튼은 모두 보입니다.
- 안을 전환하면 현재 날짜와 메뉴를 유지합니다. 다른 사람의 화면은 바뀌지 않습니다.
- 특정 안의 변경은 해당 데이터 파일만 수정합니다. 다른 안에 일괄 반영하지 않습니다.
- 원본을 기준으로 세 파일을 동일하게 복사했습니다. 이후 안별 차이가 생기는 것은 정상입니다.
- 쇼핑·준비물·환율은 이 폰에서 공통 저장, 날짜·팀·가족 미션은 안별 저장합니다. 가족 간 서버 동기화는 없습니다.
- HTML 안의 공통 안내문과 app.js의 일부 설명은 공통입니다. 안마다 달라지는 안내문을 수정할 때는 먼저 해당 안의 데이터로 분리한 다음 표시를 연결해야 합니다.
- 웹페이지의 일정 변경은 실제 식당·숙소·셔틀 예약 변경을 뜻하지 않습니다.
